# 影盒

**你的好片，自成一库。**

影盒是一款集媒体库管理、影视发现与播放于一体的应用。收藏的电影、追着的剧，还有今晚想看的，从电脑到客厅，都能在这里找到。

[下载与版本说明](https://github.com/Acefake/yingbox-releases/releases) · [问题反馈](https://github.com/Acefake/yingbox-releases/issues)

## 主要功能

- **本地媒体库**：扫描电影和剧集目录，识别片名、季集与多版本，从 TMDB 获取海报、剧情和演员资料，以海报墙浏览收藏。
- **文件整理**：按模板整理媒体文件，写入 Kodi 标准 NFO、海报和剧照。
- **影视发现与搜索**：浏览豆瓣影片，通过自行配置的 CMS 与插件源统一搜索、选源测速、播放和 HLS 下载。
- **网盘与追更**：支持 115 网盘建库、追更日历与按剧设置转存目标，转存后通知媒体库扫描；可连接 CloudDrive2 变更通知进行增量扫描。
- **媒体播放**：支持本地文件、HLS、多音轨和外挂字幕。桌面端提供独立播放窗口，也可使用 mpv；网页端在页面内播放。
- **跨端访问**：提供桌面、网页、安卓手机与电视端，也可将片库服务部署到 NAS。安卓手机与电视可连接 NAS 片库并直接播放。

各端功能随设备与部署方式有所不同。HDR 与杜比视界的实际输出取决于片源、播放内核、设备和显示器，以当前设备的播放诊断为准。

## 开始使用

1. 前往 [Releases](https://github.com/Acefake/yingbox-releases/releases)，选择适合设备的安装包，查看对应版本说明。
2. 在设置中配置 TMDB 访问令牌，用于获取影片资料与图片。
3. 添加电影或剧集目录并开始扫描；需要在线观看时，自行配置数据源。
4. 打开片库，挑一部想看的。

## 技术概览

桌面端使用 Electron、Vue 3 与 TypeScript，媒体扫描和在线引擎在独立后台进程中运行。网页与 NAS 版本使用 Node.js 片库服务；安卓手机与电视采用原生界面。播放能力结合内置播放器、HLS 与 mpv 等组件，具体可用内核随平台而异。
